## The handbook's point of view

The best explanation names the constraint first. A queue is useful because it separates work in time. A cache is useful because it avoids repeating an expensive read. A retry is safe only when the operation can tolerate being repeated.

The pages in this handbook keep returning to those mechanics. They use diagrams when a shape matters, examples when a sequence matters, and reference tables when you need to look something up.
